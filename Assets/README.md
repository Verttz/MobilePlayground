# MobilePlayground Unity Project Structure

- **Assets/**
  - **Scripts/**: C# scripts for game logic
  - **Scenes/**: Unity scene files
  - **Prefabs/**: Prefabricated game objects
  - **Sprites/**: 2D art assets
  - **Audio/**: Sound effects and music
